# Wedding Landing Page

A modern and elegant landing page for a wedding event, designed to share essential information with guests in a clean and welcoming way.

## Overview
This project was created to present the event details, provide the location, show the dress code, and allow guests to confirm attendance. The design focuses on elegance, readability, and mobile responsiveness.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Event location section
- RSVP confirmation
- Dress code guidance
- Guest information
- Responsive layout for mobile and desktop
